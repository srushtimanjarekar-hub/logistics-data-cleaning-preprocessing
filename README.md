# Logistics Data Collection, Cleaning, and Preprocessing

## Internship
YuvaIntern – Week 2 Task

## Project Overview
This project focuses on preparing logistics and e-commerce delivery data for analysis. It uses the Olist Brazilian E-Commerce dataset to demonstrate data collection, data cleaning, preprocessing, feature engineering, and exploratory data analysis using Python.

## Objectives
- Explore and understand the dataset.
- Identify missing values and duplicate records.
- Clean and convert data types.
- Identify potential outliers in delivery time.
- Create useful delivery-related features.
- Scale numerical data for analysis.
- Export the cleaned dataset to CSV.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Files Included
- `YuvaIntern_Week_2_task.ipynb` – Notebook containing the Python code and analysis.
- `clean_delivery_data.csv` – Cleaned dataset generated by the notebook.
- `YuvaIntern_Week2_Data_Collection_Cleaning_Preprocessing_Report.docx` – Week 2 project report.

## Workflow
1. Data collection and loading.
2. Data exploration.
3. Missing-value and duplicate checks.
4. Data type conversion and validation.
5. Outlier detection.
6. Feature engineering.
7. Numerical scaling.
8. Exporting the cleaned dataset.

## Outcome
The project demonstrates a structured workflow for preparing delivery data for further logistics analysis. Actual results are available in the notebook outputs.
